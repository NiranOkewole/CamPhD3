# CamPhD3

Machine Learning Models for ADHD Data Analysis

## Overview

This project implements machine learning stacking techniques applied to ADHD research data. The work explores ensemble learning methods to improve predictive model performance.

## Contents

- `stacking-practical-adapted-ADHD-v2-Github.ipynb` - Main Jupyter notebook containing the stacking implementation and analysis

## Requirements

See `requirements.txt` for all dependencies.

### Key Dependencies

- **NumPy & Pandas**: Data manipulation and numerical computing
- **Scikit-learn**: Machine learning algorithms and preprocessing
- **XGBoost**: Gradient boosting models for stacking
- **Matplotlib & Seaborn**: Data visualization
- **Jupyter**: Interactive notebook environment

## Installation

1. Clone the repository:

```bash
git clone https://github.com/NiranOkewole/CamPhD3.git
cd CamPhD3
```

2. Install Python and start a Google Colab environment

3. Install dependencies

```bash

pip install -r requirements.txt
```

4. Start notebook

```bash
jupyter notebook
```

## Usage

Run the `stacking-practical-adapted-ADHD-v2-Github.ipynb` notebook to execute the machine learning stacking analysis on ADHD data.
